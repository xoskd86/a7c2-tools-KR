| **세로 표시** | 카메라를 세로로 들면 촬영 정보와 아이콘이 회전합니다. MENU 전체는 회전하지 않습니다. |
| **공장 기능 복원** | 이 프로젝트가 한 모든 변경을 제거하고 순정 2.01 동작으로 되돌립니다. **이전 백업이 필요 없으며**, 카메라 본체 보정값은 유지됩니다. |

## 시작하기 전에

- **배터리:** 최소 50%. 앱은 매번 쓰기 전에 전원을 확인하라고 묻습니다.
- **케이블:** 데이터 전송이 되는 USB 케이블을 컴퓨터에 직접 꽂으세요(도킹 스테이션과 허브는 피하세요). 한 번에 카메라 한 대만 연결하세요.
- **USB 모드:** 카메라의 USB 연결을 **대용량 저장장치(Mass Storage)**로 설정하세요.
- **정상적인 메시지:** 연결하거나 드라이버를 전환하는 동안 카메라에 **"연결된 기기를 확인하십시오"**가 표시되고 컴퓨터에 드라이브가 나타나지 않을 수 있습니다. 둘 다 정상입니다. 이 메시지가 아니라 앱의 진행 상황과 로그로 성공 여부를 판단하고, 이 메시지 때문에 케이블을 뽑거나 드라이버를 재설치하지 마세요.
- **쓰기 중:** 앱에 작업이 실행 중으로 표시되는 동안에는 케이블을 뽑거나, 카메라 전원을 끄거나, 앱을 닫지 마세요. 앱이 읽기/쓰기가 끝났다고 알린 뒤에만 조작하세요.
- **앱을 실행하는 것만으로는** 카메라에 연결하거나 쓰지 않습니다.

> [!NOTE]
> **콜드 리로드**(전원을 완전히 끄고 다시 켜기)는 모든 작업의 핵심 단계이며, 쓰기 후에는 매번 해야 합니다. 앱이 매번 팝업으로 안내합니다.

> 1. USB와 다른 외부 전원을 모두 분리합니다.
> 2. 액세스 램프가 깜박임을 멈출 때까지 기다립니다.
> 3. 카메라 전원을 OFF로 하고 화면과 액세스 램프가 꺼질 때까지 기다립니다.
> 4. 배터리를 빼고 **최소 1분** 기다립니다.
> 5. 배터리를 다시 넣고 전원을 켭니다.
>
> 전원을 껐다 켜는 것만으로는 충분하지 않습니다. 새로 쓴 프로그램은 콜드 리로드 후에만 로드됩니다.

```text
1단계  드라이버 설치(Windows) ──오류──→ 드라이버 제거 → 다시 꽂기 → 다시 설치
   │      └─ 권장: USB 안정성 검사(읽기 전용). 실패하면 케이블/포트 교체
   │
2단계  이 프로젝트의 어떤 버전이든 사용한 적이 있나요? ──예──→ 공장 기능 복원 → 콜드 리로드 → 확인
   │아니요
3단계  원클릭 설치 → 콜드 리로드 → USB 다시 연결 → 계속 → 설치 완료
   │
4단계  카메라에서 룩, FL2/FL3, 셔터음, 세로 표시 확인
```

### 1단계: 드라이버 설치(Windows)

앱은 두 개의 USB ID로 카메라와 통신합니다. 일반 대용량 저장장치 `054C:0E8A`와, 인증 후의 서비스 연결 `054C:0336`입니다. 둘 다 WinUSB 계열 드라이버가 필요합니다.

1. 카메라 전원을 켜고 대용량 저장장치를 선택한 뒤 컴퓨터에 연결합니다.
2. 왼쪽 사이드바에서 **연결 및 드라이버**를 엽니다.
3. **카메라 및 드라이버 검사**를 누릅니다. 로그에 `054C:0E8A`가 표시되어야 합니다. 표시되지 않으면 케이블과 USB 모드를 확인하세요.
4. **2단계 드라이버 준비 및 연결 테스트(자동)**를 누릅니다.
   - 앱이 먼저 `0E8A`용 드라이버를 설치한 뒤, 카메라를 서비스 연결로 전환하고 `0336`이 나타나면 그 드라이버를 설치합니다.
   - Windows가 관리자 권한을 **한두 번** 요청할 수 있습니다. 예를 누르세요.
   - 이미 사용 가능한 드라이버(WinUSB, libusbK, libusb0)가 있는 ID는 그대로 둡니다.
   - 이 단계에서 카메라에 "연결된 기기를 확인하십시오"가 표시될 수 있습니다. 정상입니다.
5. 로그에 **"서비스 연결에 성공했습니다. 드라이버 준비가 끝났습니다."**가 나오면 완료입니다. 이 단계는 **카메라 펌웨어에 쓰지 않습니다**.
6. **권장:** 처음 쓰기 전에 **USB 연결 안정성 검사(읽기 전용)**를 눌러 케이블과 포트를 테스트하세요.
   - 검사는 **최소 2분** 동안 진행됩니다. 카메라의 프로그램 파일 두 개(쓰기 시 전체 리드백하는 파일과 같음)를 반복해서 읽고, 매 회차를 첫 회차와 바이트 단위로 비교합니다.
   - 읽기 오류, 불일치, 또는 한 번의 읽기가 20초를 넘으면 검사에 실패합니다.
   - 읽기만 하며 카메라에 절대 쓰지 않습니다.
   - 쓰기나 리드백 중에 연결이 끊기면 결과가 "알 수 없음" 상태가 될 수 있고, 이 경우 복구가 어렵습니다. 쓰기 전에 연결이 안정적인지 확인하세요.
   - 검사에 실패하면 통과할 때까지 다른 케이블이나 컴퓨터 뒷면의 USB 포트를 사용해 보세요.
   - 통과했다고 해서 쓰기 중에 연결이 절대 끊기지 않는다는 보장은 아닙니다. 쓰는 동안 케이블과 전원을 안정적으로 유지하세요.

> [!TIP]
> 원클릭 설치도 시작할 때 드라이버를 검사하고 준비합니다. 이 단계를 먼저 따로 해 두면 무언가를 쓰기 전에 드라이버 문제를 발견할 수 있습니다.

**macOS:** 드라이버 설치가 필요 없습니다.
- 사진, 이미지 캡처 등 카메라의 메모리 카드를 사용할 수 있는 프로그램을 모두 닫으세요.
- **연결 및 드라이버**에서 **USB 서비스 연결 준비**를 누릅니다.
- 카메라 작업마다 터미널 창이 열립니다. 앱이 sudo로 USB를 넘겨받을 수 있도록 그곳에 **Mac 로그인 암호**를 입력하세요. 앱은 암호를 읽거나 저장하지 않으며, 입력하기 전에 창을 닫으면 카메라 작업이 취소됩니다.

### 드라이버 오류: 제거 후 다시 설치

다음과 같은 경우 드라이버 상태가 잘못되었을 수 있습니다.
- 1단계가 실패하거나, `0336`이 나타났지만 인터페이스를 열 수 없다고 보고되는 경우.
- 이전에 Zadig 같은 도구로 다른 드라이버를 설치한 경우.
- 연결할 때마다 Windows가 카메라를 계속 잘못 인식하는 경우.

이럴 때는 **먼저 제거한 뒤 1단계로 다시 설치하세요.**

1. **연결 및 드라이버**에서 **카메라 드라이버 제거, Windows 기본 연결로 복원**을 누릅니다. 확인한 뒤 Windows 창에서 관리자 권한을 허용합니다.
   - Sony `054C:0E8A`와 `054C:0336`의 서드파티 드라이버만 제거합니다. 다른 장치는 건드리지 않으며 카메라 펌웨어도 수정하지 않습니다.
   - 드라이버 패키지는 제거 전에 작업 폴더에 백업됩니다.
2. 로그를 따르세요.
   - 보통은 **USB를 뽑았다가 대용량 저장장치 모드로 다시 꽂으면** Windows가 기본 드라이버를 다시 연결합니다.
   - 로그에 Windows 재시작이 필요하다고 나오면 컴퓨터를 재시작하세요(앱이 직접 재시작하지는 않습니다).
3. [1단계](#1단계-드라이버-설치windows)로 돌아가 **2단계 드라이버 준비 및 연결 테스트(자동)**를 다시 누릅니다.

그래도 실패하면 다른 케이블과 컴퓨터 뒷면의 USB 포트를 사용해 보고, **USB 연결 안정성 검사(읽기 전용)**로 원인을 좁혀 보세요. 그래도 안 되면 창 아래쪽의 **진단 패키지 내보내기**를 눌러 커뮤니티에 공유하세요.

### 그래도 실패하면: Zadig로 설치

앱의 자동 드라이버 설치가 실패하는 컴퓨터에서도 [Zadig](https://zadig.akeo.ie/)로 직접 드라이버를 설치하면 대개 성공합니다. 카메라에는 아무것도 쓰지 않으며, 이 컴퓨터가 카메라의 두 USB ID에 사용하는 드라이버만 바꿉니다.

앱의 **연결 및 드라이버** 페이지에서 **2단계 드라이버 준비 및 연결 테스트(자동)** 옆에 있는 **Zadig로 드라이버 수동 설치(자동 실패 시)** 버튼을 누르면 Zadig 다운로드 링크와 함께 아래와 같은 단계가 표시됩니다.

**먼저: 카메라에는 USB ID가 두 개 있으며, 둘 다 드라이버가 필요합니다**

| 단계 | Zadig에 표시되는 이름 | USB ID | 나타나는 시점 |
| --- | --- | --- | --- |
| 일반 연결 | `ILCE-7CM2` | `054C` `0E8A` | 카메라 전원 켜짐, 대용량 저장장치 선택, 연결됨 |
| 서비스 모드 | `Sony USB Device` | `054C` `0336` | 앱이 인증한 뒤에만. 카메라에는 보통 "연결된 기기를 확인하십시오"가 표시됨 |

**준비**

1. Zadig 웹사이트에서 최신 `zadig-x.x.exe`를 내려받습니다(단일 파일, 설치 불필요).
2. 이 앱을 완전히 닫습니다.
3. 카메라 전원을 켜고 메뉴에서 USB 연결을 **대용량 저장장치(Mass Storage)**로 설정합니다. 데이터 케이블로 직접 연결하세요. 허브는 사용하지 말고, 데스크톱 PC라면 뒷면 포트를 사용하세요.

**1부: `0E8A` 드라이버**

1. Zadig를 마우스 오른쪽 버튼으로 눌러 **관리자 권한으로 실행**을 선택합니다. 업데이트 확인 여부를 물으면 아무거나 골라도 됩니다.
2. **Options** 메뉴에서 **List All Devices**를 체크합니다. 체크하지 않으면 카메라가 보이지 않습니다.
3. 위쪽 드롭다운에서 **`ILCE-7CM2`**를 선택합니다.
4. **USB ID가 `054C` `0E8A`인지 확인하세요.** 다르면 잘못 선택한 것이니 다른 항목을 고르세요. 키보드, 마우스, USB 메모리, 네트워크 어댑터 등 다른 장치의 드라이버는 바꾸지 마세요.
5. 현재 드라이버(예: `USBSTOR`)는 초록색 화살표 왼쪽에 있습니다. 화살표 오른쪽의 드라이버 칸에서 위/아래 화살표로 **libusbK**를 선택합니다.
6. 큰 **Replace Driver** 버튼을 누릅니다(드라이버가 아직 없으면 **Install Driver**로 표시됩니다). **The driver was installed successfully**가 나올 때까지 1–2분 기다립니다.
7. 그 뒤 카메라 드라이브가 사라지고 카메라에 "연결된 기기를 확인하십시오"가 표시됩니다. 둘 다 정상입니다.

**2부: `0336`이 나타나게 한 뒤 드라이버 설치**

1. Zadig는 열어 둔 채로, 이 앱에서 **연결 및 드라이버**를 열고 **2단계 드라이버 준비 및 연결 테스트(자동)**를 누릅니다.
2. 앱이 방금 설치한 `0E8A` 드라이버로 인증합니다. 그러면 카메라가 `Sony USB Device`(`054C 0336`)로 바뀝니다.
   - 앱이 `0336` 드라이버까지 직접 설치하고 로그에 **"서비스 연결에 성공했습니다. 드라이버 준비가 끝났습니다."**가 나오면 완료입니다. 3부로 가세요.
   - 로그에 `0336` 드라이버가 없다, 인터페이스를 열 수 없다, 또는 `0336`이 끝내 나타나지 않는다고 나오면: **케이블을 뽑거나 카메라를 끄지 말고** 다음 단계로 진행하세요.
3. Zadig로 돌아가 **Options → List All Devices**를 다시 눌러 새로 고칩니다. **`Sony USB Device`**를 선택하고 **USB ID가 `054C` `0336`인지 확인하세요.**
   - 목록에 `0336`이 없으면 카메라가 이미 서비스 모드를 빠져나온 것입니다. 이 부분의 1단계를 반복하고, `0336`이 나타나면 바로 Zadig를 새로 고치세요.
4. 다시 **libusbK**를 선택하고 **Replace Driver** 또는 **Install Driver**를 누른 뒤 성공 메시지를 기다립니다.

**3부: 전원을 껐다 켜고 다시 테스트**

1. USB를 뽑고 카메라 전원을 끈 뒤 **배터리를 약 1분간 분리**합니다. 다시 넣고 전원을 켜서 대용량 저장장치를 선택하고 다시 연결합니다.
2. 이 앱에서 **2단계 드라이버 준비 및 연결 테스트(자동)**를 다시 누릅니다. 로그에 **"서비스 연결에 성공했습니다. 드라이버 준비가 끝났습니다."**가 나오면 [3단계: 원클릭 설치](#3단계-원클릭-설치)로 진행하세요.

**결과 확인:** Windows 장치 관리자에 **libusbK USB Devices** 분류가 있고 그 안에 `ILCE-7CM2`가, `0336` 드라이버까지 설치했다면 `Sony USB Device`도 있어야 합니다.

**문제가 생기면**

- **libusbK 설치 실패:** Zadig를 관리자 권한으로 다시 실행하세요. 그래도 실패하면 **WinUSB**를 선택하세요. 앱은 WinUSB, libusbK, libusb0 중 어느 것이든 사용할 수 있습니다.
- **드롭다운에 카메라가 없음:** **List All Devices**를 체크했는지, 카메라가 켜져 있고 대용량 저장장치 모드인지 확인하고, 다른 데이터 케이블을 사용해 보세요.
- **되돌리려면:** **연결 및 드라이버** 페이지에서 **카메라 드라이버 제거, Windows 기본 연결로 복원**을 누르세요. Zadig로 설치한 드라이버도 함께 제거됩니다. 그 뒤 USB를 뽑았다 꽂으면 카메라가 다시 드라이브로 나타납니다.
- **Mac은 드라이버가 필요 없습니다.**

### 2단계: 이전 버전을 설치한 적이 있다면 먼저 공장 기능 복원

**이 카메라에 이 프로젝트의 어떤 버전이든 사용한 적이 있다면, 3.0을 설치하기 전에 공장 기능을 복원하세요.** FL23 v1.0/v2.x, `lut.py`, `shutter.py`, `vertical.py`로 가져온 룩, 이전 데스크톱 프리뷰가 모두 해당합니다. 이전 버전의 흔적을 지워 3.0이 깨끗한 순정 2.01 상태에서 시작하도록 합니다.

한 번도 수정하지 않은 카메라는 이 단계를 건너뛰어도 됩니다.

1. 카메라에서 크리에이티브 룩을 **ST**로 바꿉니다.
2. **공장 기능 복원**을 열고 **공장 2.01 기능 복원／복원 계속(이전 백업 불필요)**을 누릅니다. 전원을 확인하면 시작됩니다.
   - 앱에 수정 영역의 순정 2.01 데이터가 내장되어 있어 이전 백업이나 펌웨어 다운로드가 필요 없습니다.
   - 카메라 본체 보정값, 카운터, 관련 없는 설정은 유지됩니다.
3. 쓰기와 전체 리드백이 끝나면 **복원이 아직 끝나지 않았다**는 팝업이 나옵니다. [콜드 리로드](#시작하기-전에)를 하고 카메라에 라이브 뷰가 나오는지 확인하세요.
4. USB(대용량 저장장치)를 다시 연결하고 **재시작 후 확인하고 복원 완료**를 누릅니다. 이 확인을 통과해야만 복원이 완료되며, 그 뒤 앱이 이전 설치 상태를 지웁니다.

> [!WARNING]
> 복원하면 커스텀 슬롯 6개가 모두 ST로 설정됩니다. 그 안에 있던 레시피는 **되찾을 수 없습니다**. 남겨 두고 싶은 설정이 있으면 먼저 적어 두세요.

복원이 중단되면 같은 버튼을 다시 누르세요. 앱이 카메라의 현재 상태를 읽고 남은 부분만 마칩니다. 버튼이 **전원 차단 후 복원 재시도(이번에는 아직 쓰지 않음)**로 바뀌었다면 이번에는 아무것도 쓰지 않은 것입니다. 팝업에 따라 콜드 리로드를 한 뒤 누르세요.

### 3단계: 원클릭 설치

> [!IMPORTANT]
> 원클릭 설치 전에 [1단계](#1단계-드라이버-설치windows)를 마치고, 로그에 "서비스 연결에 성공했습니다. 드라이버 준비가 끝났습니다."가 나왔는지 확인하세요. 설치 실패의 상당수는 드라이버가 동작하기 전에 원클릭 설치를 시작한 경우입니다. 컴퓨터에서 처음 실행할 때도 앱이 알려 줍니다. 드라이버가 설치되지 않으면 [Zadig로 설치](#그래도-실패하면-zadig로-설치)를 사용하세요.

1. **홈 · 원클릭 설치**를 엽니다. 기본으로 다음 항목이 선택되어 있습니다.
   - **내장 룩 6종 설치**(커스텀 슬롯 1–6을 교체, Sony 기본 크리에이티브 룩은 유지)
   - **FL2／FL3 활성화**
   - **Sony 네이티브 전자 셔터음 활성화**
   - **세로 촬영 정보 표시를 켬으로 저장**
   - **Lightroom 자동 인식 플러그인 설치**: 선택 사항이며, 이 컴퓨터에 Lightroom Classic이 필요합니다
2. **원클릭 설치**를 누르고 전원을 확인합니다. 앱이 드라이버를 검사하고, 선택한 모든 옵션을 한 번의 쓰기로 합친 뒤 전체를 리드백합니다.
3. 팝업에 읽기/쓰기가 끝났다고 나오면 [콜드 리로드](#시작하기-전에)를 합니다.
4. 카메라 전원을 켜고 USB(대용량 저장장치)를 다시 연결한 뒤 홈에서 **설치 계속**을 누릅니다. 같은 버튼입니다. 앱은 카메라가 재시작해 변경 사항을 로드했는지 확인한 뒤 사운드와 플러그인을 설정합니다. **다시 쓰는 것은 없습니다.**
5. **설치 완료** 팝업에 설치된 룩과 기능이 표시됩니다. 나중에 **지난 설치 결과 보기(카메라 연결 안 함)**로 다시 열 수 있습니다.

이름은 기록되었지만 프로그램은 아직 쓰지 않았다는 메시지가 나오면, 카메라가 아직 이전 리소스를 붙잡고 있는 것입니다. 팝업에 따라 콜드 리로드를 하고 다시 연결한 뒤 **설치 계속**을 다시 누르세요. 이름은 두 번 쓰지 않습니다.

**기본 룩 6종:**

| 커스텀 슬롯 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 룩 | Classic Neg. (NC) | Classic Chrome (CC) | Nostalgic Neg. (NN) | Astia | GR Positive Film | GR Negative Film |

직접 만든 룩을 설치하려면 내장 6종의 체크를 해제하고, **직접 만든 A7Look 파일 사용(먼저 내장 6종 체크 해제)**을 펼쳐 슬롯마다 `.a7look` 파일을 고르세요. 비워 둔 슬롯은 그대로 유지됩니다.

### 4단계: 카메라에서 확인

- ST와 각 커스텀 슬롯 사이를 전환해 보세요. 라이브 뷰가 즉시 바뀌어야 합니다. 사진을 찍고 재생해 보세요.
- 각 커스텀 슬롯의 기본 룩은 ST로 두세요. 다른 기본 룩을 쓰면 커스텀 룩이 적용되지 않을 수 있습니다.
- 크리에이티브 룩 목록에서 FL2와 FL3를 선택, 촬영, 재생할 수 있는지 확인하세요.
- 전자 셔터로 촬영해 소리를 들어 보세요. 소리가 나지 않으면 카메라의 오디오 신호음 설정을 확인하세요.
- 카메라를 세로로 들고 촬영 정보가 회전하는지 확인하세요.

내장 룩은 원본 DCP를 피팅한 근사치이므로 색이 DCP와 정확히 같지 않을 수 있습니다.

## 기능별 개별 사용

모든 쓰기는 같은 흐름을 따릅니다: 쓰기 → 전체 리드백 → 콜드 리로드를 요청하는 팝업. 1단계를 마쳤다면 각 페이지를 따로 사용할 수 있습니다.

### FL2 / FL3

- **FL2 / FL3 활성화／다시 활성화**: 쓰기 후 콜드 리로드하세요. 카메라에서 선택할 수 있으면 완료이며, 다시 연결해 확인할 필요는 없습니다.
- **목록에서 FL2 / FL3 제거, 커스텀 룩은 유지**: 메뉴 항목만 숨깁니다. 커스텀 룩이 쓰는 공용 코드는 남아 있으므로 나중에 다시 활성화할 수 있습니다.
- 제거하기 전에 카메라를 ST로 바꾸세요.

### 커스텀 크리에이티브 룩

1. 바꾸려는 슬롯마다 **+ 작업 항목 추가**를 한 번씩 누릅니다.
   - **A7Look 쓰기**: `.a7look` 파일을 고르고, 원하면 카메라에 표시할 이름을 입력합니다(비워 두면 파일에 저장된 이름 사용).
   - **ST 기본값으로 복원**: 슬롯을 ST로 되돌립니다. 새 항목의 기본값입니다.
2. **이 N개 변경 사항 확인 후 적용**을 누르고 목록을 확인한 뒤 승인합니다. 목록의 모든 슬롯을 한 번에 쓰며, 다른 슬롯은 건드리지 않습니다.
3. 콜드 리로드하면 바로 사용할 수 있습니다. 별도 확인은 필요 없습니다.

> [!NOTE]
> 커스텀 룩은 **ST를 기본 룩으로** 해서 기록됩니다. 카메라에서 해당 커스텀 슬롯을 선택하기만 하면 되며, 크리에이티브 룩을 ST로 바꿀 필요는 없습니다. 다만 카메라 메뉴에서 해당 커스텀 슬롯의 기본 룩을 ST가 아닌 다른 것으로 바꾸면 커스텀 룩이 적용되지 않거나 색이 틀어질 수 있으며, ST로 되돌리면 해결됩니다. 카메라가 이 옵션을 잠그지는 않습니다.

같은 페이지의 도구:
- **내장 DCP／A7Look 짝 라이브러리 열기**: 15쌍(후지필름 11, 리코 4). 각 DCP가 같은 이름의 `.a7look` 옆에 있습니다.
- **DCP／LUT로 A7Look 생성…**: 오프라인 변환이며 카메라에 연결하지 않습니다.
  - **CUBE**는 **Sony ST / sRGB** 입력, sRGB 출력이어야 합니다. **S-Log3 같은 Log LUT는 바로 사용할 수 없습니다.** [LUT 형식과 색 공간](docs/en/lut-formats.md)(영문)을 참조하세요. 앱의 **LUT 형식 안내** 버튼에서도 한국어 설명을 볼 수 있습니다.
  - **DCP**는 앱이 직접 해석하고 피팅하며, Lightroom이 필요 없습니다.
- **LrC 자동 인식 플러그인 설치…**: 설치 후 Lightroom의 플러그인 관리자에서 한 번 활성화하세요. 그 뒤로는 RAW 파일을 가져올 때 각 사진에 사용한 슬롯의 DCP를 적용합니다. RAW 데이터 자체는 절대 바꾸지 않습니다.

### 전자 셔터음

1. **전자 셔터음 켜기**: Sony 네이티브 전자 셔터음을 켭니다. 쓰기 후 콜드 리로드하세요.
2. 오디오 또는 영상 파일을 고르고 **시작점**과 **길이**(0.01–2초)를 설정한 뒤 **선택 구간 변환**을 누릅니다. 컴퓨터에서만 처리합니다.
3. 원하면 **음량 낮추기 −3 dB / 음량 높이기 +3 dB / 변환 당시 음량으로 되돌리기**로 음량을 조절합니다.
4. **현재 커스텀 사운드 저장**을 누르고, 쓰기 후 콜드 리로드하세요.
5. **카메라에서 임시 미리 듣기**는 선택입니다. 미리 듣는 동안에는 **카메라 전원을 켜 둔 채로** USB를 뽑고 시험 촬영하세요. 마음에 들면 다시 연결해 저장합니다.
6. 원래 소리로 돌아가려면 **순정 효과음으로 복원**을 누르세요.

### 세로 표시

> [!NOTE]
> 세로 메뉴 프레임은 다시 작성하는 중입니다. 작업이 끝나면 이 절을 업데이트합니다.

- **세로 표시 켜기**: 스위치를 저장합니다. 콜드 리로드 후 카메라를 세로로 들면 촬영 정보와 아이콘이 회전합니다.
- **세로 표시 끄기**: 먼저 끈 뒤 관련 변경을 되돌립니다.
- 두 버튼 모두 다시 눌러도 안전하며, 상태가 이미 같으면 다시 쓰지 않습니다.

### 공장 기능 복원

[2단계](#2단계-이전-버전을-설치한-적이-있다면-먼저-공장-기능-복원)를 참조하세요. 고급 영역에는 다른 복원 방법 두 가지도 있습니다.
- 완전한 순정 `BODYDATA.DAT`를 가져와 그것으로 복원.
- 이전 카메라 본체 백업(예전 FL23이나 `lut.py` 버전이 만든 백업)으로 과거 상태로 되돌리기.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 카메라에 "연결된 기기를 확인하십시오"가 표시됨 | 정상입니다. 앱의 로그를 따르세요. |
| `054C:0E8A`를 찾지 못함 | 카메라가 대용량 저장장치 모드가 아니거나 케이블이 데이터를 전송하지 못합니다. 고친 뒤 다시 꽂으세요. |
| `0336`이 끝내 나타나지 않음 | 앱이 잠시 대기 후 최대 3회까지 자동으로 재시도합니다. 그래도 실패하면 [드라이버 오류](#드라이버-오류-제거-후-다시-설치) 또는 [Zadig로 설치](#그래도-실패하면-zadig로-설치)를 참조하세요. |
| 인증 후 카메라가 재생 화면으로 넘어가고 `0336`이 나타나지 않음 | 컴퓨터의 USB 2.0 포트(또는 USB 2.0 케이블이나 허브)를 사용해 보세요. 일부 컴퓨터에서는 USB 3 고속 링크로는 카메라가 서비스 모드에 진입하지 않습니다. |
| `0336`은 나타나지만 인터페이스를 열 수 없음 | 드라이버 문제입니다. 드라이버를 제거하고 다시 설치하세요. 설치 버튼을 계속 누르지 마세요. |
| 설치나 복원이 중단됨 | **같은 버튼**을 다시 누르세요. 앱이 현재 상태를 읽고 멈춘 곳부터 이어 가며, 완료된 부분은 다시 쓰지 않습니다. |
| 앱이 알 수 없는 결과를 보고하거나 확인을 요청함 | **쓰기를 재시도하지 마세요.** **진단 패키지 내보내기**를 눌러 커뮤니티에 공유하세요. |
| 셔터음이 나지 않음 | 카메라 메뉴에서 오디오 신호음이 켜져 있는지 확인하세요. |
| 룩 색이 DCP와 조금 다름 | 정상입니다. 카메라 내부 테이블은 피팅 근사치입니다. |
| Mac에서 터미널이 암호를 요구함 | Mac 로그인 암호를 입력하세요. sudo가 USB를 넘겨받는 데 사용합니다. |

진단 패키지에는 장치 정보와 로컬 경로가 들어 있으므로, 공개적으로 공유하기 전에 내용을 확인하세요. 펌웨어, 본체 보정값, 사진은 절대 포함되지 않습니다.

## 명령줄 및 개발

일상적인 사용은 인터페이스로 충분합니다. 원래의 명령줄 도구는 고급 사용자와 개발을 위해 남아 있습니다.

| 진입점 | 용도 |
| --- | --- |
| `python desktop.py` | 소스에서 데스크톱 앱 실행(64비트 Python 3.11, 먼저 `pip install -r desktop-requirements.txt`) |

| `python recovery.py` | 원본 백업에서 전체 롤백 |
| `python a7look_compile.py` | 오프라인 DCP/CUBE → `.a7look` 컴파일러 |

오프라인 테스트(카메라 접근 없음): `python -m pytest dev/desktop -q`. 구조, 빌드, 패키징: [개발 가이드](docs/en/development.md)(영문). AI에게 코드를 수정하게 하기 전에 [AGENTS.md](AGENTS.md)를 읽으세요.

## 감사의 말

(원작자의 글) 제 첫 오픈소스 프로젝트인데, 이렇게 많은 관심과 응원을 받을 줄은 몰랐습니다. 모두 감사합니다.

- **공동 작업자:** FL23 리팩터링, USB 호환성 수정, 사진/동영상 커브 라우팅([#5](https://github.com/QAQLeonard/a7c2-fl23-research/pull/5), [#6](https://github.com/QAQLeonard/a7c2-fl23-research/pull/6))을 해 준 [@UzLung1435](https://github.com/UzLung1435), 그리고 이슈를 열고 풀 리퀘스트를 보내고 아이디어를 나눠 준 모든 분께 감사드립니다.
- **색상:** DCP를 제공해 준 샤오훙수의 **门萨特里顿**과 **爸总林先森**, 그리고 색 기준을 피팅하고 비교하는 데 도움을 준 커뮤니티 회원들께 감사드립니다. 여러분이 없었다면 내장 룩은 존재하지 않았을 것입니다.
- **이 작업의 기반이자 인용한 프로젝트:**
  - [lzh2016zzz/a7cr-fl23-research](https://github.com/lzh2016zzz/a7cr-fl23-research): A7CR의 FL2/FL3 이식 연구로, 이 프로젝트의 파라미터, 라벨, WBI 방법의 출발점입니다.
  - [Hearts-Ace/sony-a7r5-custom-firmware](https://github.com/Hearts-Ace/sony-a7r5-custom-firmware): A7R V의 FL2/FL3 펌웨어 적용 및 RAW 색상 연구로, FL2/FL3 색상 데이터 이식의 핵심 참고 자료입니다.
  - [MDHan/a7c2-fl23-macos](https://github.com/MDHan/a7c2-fl23-macos): A7C II의 macOS 버전으로, Mac에서 카메라 저장소를 식별하고 USB를 넘겨받는 방법의 참고 자료입니다.
  - [ma1co/Sony-PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE), [ma1co/fwtool.py](https://github.com/ma1co/fwtool.py), [YuuLuo/a7c2-service-preload](https://github.com/YuuLuo/a7c2-service-preload): 서비스 모드 통신, 펌웨어 해석, A7C II 서비스 모드 연구.
  - 그리고 이 프로젝트를 인용하고, 공유하고, 기반으로 삼아 준 모든 개발자께 감사드립니다.
- **테스터:** 자신의 카메라로 테스트하고 끈기 있게 로그를 보내 준 모든 분께 감사드립니다. 모든 보고가 도구를 더 안전하게 만들었습니다.
- **모두에게:** 별을 눌러 주고, 공유하고, 커뮤니티 채팅에 참여해 준 모든 분께 감사드립니다. 여러분 덕분에 이 프로젝트가 3.0까지 왔습니다.
